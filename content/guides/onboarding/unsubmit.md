# Unsubmit student work
Fiona MacNeill | 8 steps | 1 minute<br>
<strong>28 June 2026</strong><br>
1. If a student accidentally submits the incorrect files, a teacher can return their work to them by using the “Unsubmit” feature. As an added point, Kita allows multiple submissions. So if a student submits an incorrect file, as alternative they can also submit a second replacement file without the teacher’s intervention. <br> 
&nbsp;
2. You can “Unsubmit” a student’s work from the teacher view of their work in the IDE. <br>You can reach this view from “People” \(live teaching\), “student progress” \(asynchronous checks\), and from “marking” \(assessments\). We show the route from “marking” in this tutorial.<br> 
&nbsp;
